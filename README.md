# 🎬 Movies Project

مشروع واجهة أمامية (Frontend) معمول باستخدام **React.js** لعرض مجموعة من الأفلام بشكل منسق مع مميزات أساسية زي:

## ✨ المميزات
- ✅ **Navbar ديناميكي**: يحتوي على روابط تنقلك مباشرة إلى أقسام الصفحة (Home - About - Contact).
- ✅ **بطاقات الأفلام (Cards)**: عرض صور + عناوين + وصف لكل فيلم.
- ✅ **نظام Like/Unlike**: يمكن للمستخدم إضافة لايك أو إزالته، مع تخزين الحالة في Local Storage.
- ✅ **محرك بحث (Search)**: للبحث عن الأفلام بالعنوان بشكل مباشر.
- ✅ **تصميم متجاوب (Responsive Design)**: متوافق مع الشاشات المختلفة (موبايل، تابلت، لابتوب).
- ✅ **Footer احترافي**: يحتوي على أيقونات تواصل اجتماعي مع تأثير Hover.

## 🛠️ التقنيات المستخدمة
- **React.js**
- **CSS3 (Flexbox + Media Queries)**
- **JavaScript (ES6+)**
- **Local Storage**
